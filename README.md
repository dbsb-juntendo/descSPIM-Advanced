# descSPIM-Advanced
The descSPIM-Advanced platform was developed to overcome the limitations of the initial descSPIM-basic, introducing four interoperable variants: FullMoon for uniform wide-field imaging, DeepSky for subcellular resolution, Galaxy for >10-color 3D hyperspectral imaging, and SLIM as a ~USD 15 k accessible model.
